# 厦漳泉企业关系 OD 统计——字段与计算口径说明

## 一、统计范围

三个源文件均只保留同时满足以下条件的记录：

1. O 端城市字段属于“厦门市、漳州市、泉州市”；
2. D 端城市字段属于“厦门市、漳州市、泉州市”；
3. O 端区县字段非空；
4. D 端区县字段非空。
5. O 端与 D 端不是同一个区县，即 `(o_city, o_county) != (d_city, d_county)`。

投资、分支关系保留 **O 端 → D 端** 方向；专利关系改为无向关系，A/B端仅按城市、区县和企业键排序以保持输出稳定，不代表方向。

计算前统一更新区县名称：`龙海市 → 龙海区`、`长泰县 → 长泰区`。源文件中的其他厦门、漳州、泉州区县名称与现行县级行政区划名称一致。

行业目录统一使用 `编码/行业代码表db_code_t_industry_code.xlsx`。代码表中的补零编码按层级规范化：一级 `A0000 → A`、二级 `A0100 → A01`、三级 `A0110 → A011`；行业名称以代码表为准。当前汇总和网站使用一级至三级，代码表第四级暂不纳入筛选。

## 二、投资关系

源文件：`t_hu_investments_it_xzq.xlsx`

| 计算内容 | 使用的源字段 | 说明 |
|---|---|---|
| O 端企业ID | `eid` | 投资企业ID；缺失时以 `name` 代替 |
| O 端企业名称 | `name` | 投资企业名称 |
| D 端企业ID | `invest_eid` | 被投资企业ID；缺失时以 `invest_name` 代替 |
| D 端企业名称 | `invest_name` | 被投资企业名称 |
| O 端城市 | `o_city` | 投资企业所在城市 |
| O 端区县 | `o_county` | 投资企业所在区县 |
| D 端城市 | `d_city` | 被投资企业所在城市 |
| D 端区县 | `d_county` | 被投资企业所在区县 |
| D 端一级行业代码 | `d_industry_code1` | 用于一级行业汇总 |
| D 端一级行业名称 | `d_industry_name1` | 用于一级行业汇总 |
| D 端二级行业代码 | `d_industry_code2` | 用于二级行业汇总 |
| D 端二级行业名称 | `d_industry_name2` | 用于二级行业汇总 |
| 投资金额 | `should_capi_conv` | 原始单位按“万元原币”处理 |
| 币种 | `currency_code` | 空值按人民币 CNY 处理 |

投资关系按 `eid + invest_eid` 去重；当企业ID为空时，分别用 `name` 和 `invest_name` 作为替代键。

投资金额折算公式：

```text
投资金额（万元人民币） = should_capi_conv × 对应币种兑人民币汇率
```

统一汇率基准日为 2026-07-21：

| 币种 | 1单位外币折合人民币元 |
|---|---:|
| CNY或空值 | 1 |
| USD | 6.7684 |
| HKD | 0.8632 |
| EUR | 7.7241 |
| DEM | 7.7241 ÷ 1.95583 |

其中德国马克按固定换算关系 `1 EUR = 1.95583 DEM` 先转换为欧元，再折算为人民币。

## 三、分支机构关系

源文件：`t_hu_branches_it_xzq.xlsx`

| 计算内容 | 使用的源字段 | 说明 |
|---|---|---|
| O 端企业ID | `eid` | 总公司ID；缺失时以 `o_name` 代替 |
| O 端企业名称 | `o_name` | 总公司名称 |
| D 端企业ID | `sub_eid` | 分支机构ID；缺失时以 `d_name` 代替 |
| D 端企业名称 | `d_name` | 分支机构名称 |
| O 端城市 | `o_city` | 总公司所在城市 |
| O 端区县 | `o_county` | 总公司所在区县 |
| D 端城市 | `d_city` | 分支机构所在城市 |
| D 端区县 | `d_county` | 分支机构所在区县 |
| D 端一级行业代码 | `d_industry_code1` | 用于一级行业汇总 |
| D 端一级行业名称 | `d_industry_name1` | 用于一级行业汇总 |
| D 端二级行业代码 | `d_industry_code2` | 用于二级行业汇总 |
| D 端二级行业名称 | `d_industry_name2` | 用于二级行业汇总 |
| 分支机构注册资本 | `d_regist_capi` | 用于分支关系金额统计 |

分支关系按 `eid + sub_eid` 去重；ID为空时，分别用 `o_name` 和 `d_name` 作为替代键。

`d_regist_capi` 为文本时，程序提取其中第一个数值并识别“元/万元”和币种。例如：

- `30万元人民币` → 30万元人民币；
- `30（单位：万元）` → 30万元人民币；
- `10000元人民币` → 1万元人民币。

金额为空或不能解析时，该记录仍计入关系数量，但不计入“有金额关系数”，也不计入金额合计，不按0元处理。

## 四、专利关系

源文件：`t_hu_patents_relations_sq_xzq.xlsx`

| 计算内容 | 使用的源字段 | 说明 |
|---|---|---|
| O 端企业ID | `o_eid` | 缺失时以 `o_name` 代替 |
| O 端企业名称 | `o_name` | O 端专利关联企业 |
| D 端企业ID | `d_eid` | 缺失时以 `d_name` 代替 |
| D 端企业名称 | `d_name` | D 端专利关联企业 |
| O 端城市 | `o_city` | O 端企业所在城市 |
| O 端区县 | `o_county` | O 端企业所在区县 |
| D 端城市 | `d_city` | D 端企业所在城市 |
| D 端区县 | `d_county` | D 端企业所在区县 |
| O/D 端一级行业 | `o_industry_code1`、`o_industry_name1`、`d_industry_code1`、`d_industry_name1` | 用于一级行业对汇总 |
| O/D 端二级行业 | `o_industry_code2`、`o_industry_name2`、`d_industry_code2`、`d_industry_name2` | 用于二级行业对汇总 |
| O/D 端三级行业 | `o_industry_code3`、`o_industry_name3`、`d_industry_code3`、`d_industry_name3` | 用于三级行业对汇总 |
| 专利申请号 | `request_num_standard` | 优先作为专利唯一标识 |
| 备用专利标识 | `id` | 申请号为空时使用 |

专利关系按以下组合进行无向去重：

```text
request_num_standard（为空时使用id） + 无序企业对
```

无序企业对是将两个企业ID排序；企业ID为空时使用企业名称作为替代键。同一专利的 `A—B` 与 `B—A` 只保留一次；若一个专利涉及A、B、C三个企业，`A—B`、`A—C`、`B—C` 分别保留。专利关系只统计数量，不计算金额。

专利行业不再使用单一D端行业，而是将双方行业排序形成无序“行业对”。例如泉港区C26企业与东山县C30企业之间的关系统一表示为 `C26—C30`，不再分别形成C26和C30两组方向性统计。

方向匹配检查以同一专利、同一企业对是否同时出现 `A→B` 与 `B→A` 为准。只有单向原始记录的关系仍保留，但计入“方向不匹配关系数”，不擅自乘2或除2。

## 五、输出文件的汇总维度

### 1. 区县OD汇总.csv

投资和分支的分组字段：

```text
关系类型 + O端城市 + O端区县 + D端城市 + D端区县
```

专利采用无向区县对：

```text
关系类型 + A端城市 + A端区县 + B端城市 + B端区县
```

专利区县汇总另含唯一专利数量、唯一企业对数量、最大企业对专利数、最大企业对贡献率、集中度判断和方向不匹配关系数。

### 2. 区县一级行业OD汇总.csv

分组字段：

```text
关系类型 + O端城市 + O端区县 + D端城市 + D端区县
+ D端一级行业代码 + D端一级行业名称
```

本文件只包括投资和分支，只区分D端行业，不包括专利。

### 3. 区县二级行业OD汇总.csv

分组字段：

```text
关系类型 + O端城市 + O端区县 + D端城市 + D端区县
+ D端二级行业代码 + D端二级行业名称
```

本文件只包括投资和分支，只区分D端行业，不包括专利。

### 4. 专利一级/二级/三级行业对OD汇总.csv

分组字段：

```text
无向区县对 + 无序行业对
```

输出“专利—企业对关系数、唯一专利数量、唯一企业对数量、方向不匹配关系数”。

## 六、输出指标含义

| 输出指标 | 含义 |
|---|---|
| `关系数量` | 筛选并按上述规则去重后的关系条数 |
| `有金额关系数` | 能成功取得并解析金额的关系条数；专利固定为0 |
| `金额合计_万元人民币` | 投资或分支金额按统一汇率折算后的合计，单位为万元人民币 |
| `汇率基准日` | 投资和分支填写2026-07-21；专利留空 |
| `唯一专利数量` | 同一区县对内去重后的专利ID数量 |
| `唯一企业对数量` | 同一区县对内不重复的无序企业对数量 |
| `最大企业对贡献率` | 最大企业对涉及专利数 ÷ 该区县对唯一专利数 |
| `方向不匹配关系数` | 未发现反向原始记录的唯一专利—企业对关系数 |

源文件中的坐标、成立日期、企业状态、持股比例和实缴资本目前不参与本次汇总计算。O端行业字段仅参与专利行业对统计。
