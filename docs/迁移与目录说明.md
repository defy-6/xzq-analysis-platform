# 迁移与目录说明

迁移日期：2026-07-29

## 迁移结果

原网站从 `企业数据/xzq-relation-site` 迁入 `apps/web`。网站不再读取原“企业数据”和“人口数据”文件夹中的绝对路径，三个数据生成程序均以平台根目录为基准读取数据。

## 当前功能域

现有企业关系、人口流动和联系象限合并归入“区域联系网络”功能域，代码位于：

`apps/web/app/features/contact-network/`

后续用地、交通可达性和公共服务设施分别在 `modules/` 中建立研究资料，并在 `apps/web/app/features/` 中建立同名网页功能。

## 已迁移的数据

- 企业投资、分支、专利原始表；
- 乡镇级人口流动汇总版；
- 福建省 GeoPackage；
- 行业代码表、汇率配置、区县名称更新映射；
- 当前四象限模型结果及工作簿；
- 网站内已经采用的十二类产业链分类 CSV。

原十二类产业链 Excel 文件在迁移时已不位于此前提供的临时路径，因此本项目保存了与网站代码完全一致的十二类分类 CSV，作为当前可复算口径。
