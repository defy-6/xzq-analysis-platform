# 交通可达性模块

## 当前数据

已接入区县政府驻地之间的驾车 OD，覆盖厦门、漳州、泉州 28 个区县：

- 节点数：28；
- 有向 OD：756 条，即 `28 × 27` 个非自身组合；
- 自身 OD：0；
- 核心字段缺失：0。

原始文件位于 `data/raw/transport/driving/county-government/`。

## 区县级字段

- O/D 政府名称、省、市、区县；
- O/D WGS84 经纬度；
- 驾车路线 LINESTRING；
- 耗时（秒）、里程（米）、过路费（元）；
- 分析表增加耗时（分钟）、里程（公里）、平均速度和联系类型。

## 乡镇街级数据

乡镇街政府驾车OD已归档至 `data/raw/transport/driving/township-government/`，覆盖330个节点和108,570条有向OD，即 `330 × 329` 个完整非自身组合。区县与镇街两个层级分别生成接口，不直接混合统计。

乡镇街接口沿用区县接口的时间、距离、过路费、双向均值和节点统计字段。跨区县同名镇街组合已经补全，当前所有54,285个无向镇街对均有两个方向的驾车记录。

镇街地图底图与人口流动模块一致，完整保留405个乡镇街边界；其中330个具有政府驻地驾车OD，林场等其余75个无OD区域仅作为完整底图显示，不进入起终点树、OD列表或统计。

## 已上线功能

- 区县／乡镇街分析层级切换；
- 时间、距离、过路费指标切换；
- 跨市／市内、起点和终点层级树筛选；
- 动态分级流向图、OD排序、双向详情和 PNG 导出；
- 90分钟可达比例与当前筛选汇总；
- 联系象限模型以同一区县对 A→B 与 B→A 驾车里程的算术平均值作为无向距离阻抗。

## 后续功能

- 等时圈、方向差异与跨市走廊专题识别；
- 与人口流动、企业联系的更多联合分析。
