# 交通可达性模块

## 当前数据

已接入区县政府驻地之间的驾车 OD，覆盖厦门、漳州、泉州 28 个区县：

- 节点数：28；
- 有向 OD：756 条，即 `28 × 27` 个非自身组合；
- 自身 OD：0；
- 核心字段缺失：0。

原始文件位于 `data/raw/transport/driving/county-government/`。

## 区县级字段

- O/D 政府名称、省、市、区县；
- O/D WGS84 经纬度；
- 驾车路线 LINESTRING；
- 耗时（秒）、里程（米）、过路费（元）；
- 分析表增加耗时（分钟）、里程（公里）、平均速度和联系类型。

## 后续镇街数据

镇街政府驾车 OD 到位后放入：

`data/raw/transport/driving/township-government/`

建议至少保留与区县级一致的 O/D 名称、所属地市、区县、经纬度、路线、耗时、里程和过路费字段。区县与镇街两个层级分别建接口，不直接混合统计。

## 已上线功能

- 时间、距离、过路费指标切换；
- 跨市／市内、起点和终点区县筛选；
- 动态分级流向图、区县对排序、双向详情和 PNG 导出；
- 90分钟可达比例与当前筛选汇总；
- 联系象限模型以同一区县对 A→B 与 B→A 驾车里程的算术平均值作为无向距离阻抗。

## 后续功能

- 镇街政府 OD 到位后增加区县／镇街层级切换；
- 等时圈、方向差异与跨市走廊专题识别；
- 与人口流动、企业联系的更多联合分析。
