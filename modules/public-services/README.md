# 公共服务设施模块

## 当前数据与功能

- 数据源：`data/raw/public-services/poi/厦漳泉POI.csv`；
- POI类别按“大类 → 中类 → 小类”层级树展开，可直接选择任一层级的全部点位；
- 分类目录包含22个大类、230个大类—中类组合和1,652个大类—中类—小类组合；
- 原始分类保留“大类 → 中类 → 小类”树，同时新增九类分析分类：商业消费、餐饮休闲、产业就业、物流服务、公共管理、教育文化、医疗健康、交通门户、文旅生活；
- 网站设置“功能总体格局、区县功能结构、公共服务配置、功能集聚与中心体系、用地—POI匹配”五个专题；
- 比较口径包括数量、每万常住人口配置、每平方公里建设用地密度、功能结构占比、区位熵和对应功能用地节点承载强度；
- 常住人口使用2024年区县数据，建设用地与用地分析模块共用同一数据源；
- “龙海市”并入“龙海区”，“长泰县”并入“长泰区”；
- 排除仙游县、大田县、尤溪县、永泰县、漳平市，仅保留厦漳泉现行28区县；
- 原始接口保留1,218,223条记录；功能分析排除非功能记录245,514条并去除重复点位9,656条，最终使用963,053个有效功能型POI。

## 功能分析规则

- 排除“地名地址信息、通行设施、虚拟数据、道路附属设施”；
- 有效记录按“区县＋名称＋类型代码＋WGS84坐标”去重；
- 总量表示功能规模，建设用地密度表示节点集聚，人均指标表示相对配置，三者不可互相替代；
- POI区位熵以都市圈九类功能结构为参照，`LQ > 1.2`仅作为相对专业化的初步信号；
- 商业、产业、公共服务和交通功能分别使用对应功能用地面积计算“节点承载强度”，不将其命名为土地利用效率；
- 初步功能类型由POI规模、结构与区位熵识别，不代表行政等级或实际服务能力。

POI数量仅反映源数据中的点位计数，尚未包含医院床位、医生人数、学校学位、商业面积、设施等级与服务半径，因此标准化结果不直接等同于服务质量、供需均衡或设施可达性。
