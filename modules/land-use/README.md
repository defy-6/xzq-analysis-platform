# 用地分析模块

## 当前数据与功能

- 数据源：`data/raw/land-use/厦漳泉用地数据_整理成果.xlsx`；
- 覆盖厦门、漳州、泉州三市现行28个区县；
- 面积统一采用公顷，源文件未提供统计年份，按单期横截面分析；
- 网站支持开发强度、农用地与未利用地占比、产业开发密度、建设功能结构、中心功能、交通门户、公共空间和混合度地图；
- 模块按国土开发强度、城乡建设形态、产业空间分工、中心性与门户、区县发展类型五个专题组织；
- 国土开发专题展示三市农用地—建设用地—未利用地100%结构；城乡专题接入201城市、202建制镇、203村庄范围内建设用地；
- 产业与门户专题分项展示工业、物流、商业、公服、公共空间和港口门户功能；
- 区县类型识别以都市圈28区县中位数为可审计基准，输出六类发展标签，不使用主观权重综合排名；
- 区县详情展示三类用地构成和七类建设功能区位熵。
- 页面底部随当前指标动态展示计算公式、分子、分母、指标含义与解读注意。

未利用地不能直接解释为可开发后备土地，当前指标用于横向结构比较，不用于趋势判断。
